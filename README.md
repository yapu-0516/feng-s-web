# 长征万里，薪火千秋

作品以横向长卷讲述中央红军长征。访客可以拖动长卷、滚动滚轮、使用方向键或点击节点，从于都河走到吴起镇。场景、天气、配乐和星火进度会随位置变化。

## 作品与团队

- 作品类型：创意网站
- 代码编写：王瑛璞
- 创意与美工设计：丰玉芷

## 启动

```powershell
npm start
```

打开 `http://127.0.0.1:4173`。项目只使用 Node.js 标准库，无需安装依赖。

也可以直接打开 `index.html`。星火墙初始显示 3 条策展寄语；可以用本地演示按钮逐条增加路线星火，新留言和点赞保存在本机浏览器，无需启动或部署服务器。

拖动、明暗切换与分页配乐在直接双击打开和 `npm start` 两种方式下均可用。

## 操作

- 桌面：在长卷区域按住拖动，也可使用滚轮和左右方向键。
- 手机与平板：在长卷区域左右滑动。
- 所有设备：右侧或顶部的七颗星火按钮可直接跳转历史节点。
- 第一次点击、触摸、滚动或按键后开启配乐。页面和七个章节使用不同旋律，右上角“关配乐”可关闭。
- 支持深色与浅色主题，选择会保存在本机。
- 湘江和赤水河场景包含水光、流动线与涟漪，夹金山包含两层降雪和斜向风雪，草地包含风线。
- 行军剪影会随章节向前行进，步幅周期约 0.66 秒。到达吴起镇后，太阳从山脊后升起。
- 粒子密度会随屏幕宽度降低；系统启用“减少动态效果”后，装饰动画停止。
- 留言可以点赞。共享留言的赞数保存在项目服务器，同一浏览器不能重复点赞；离线时点赞状态保存在本机。
- 星点沿页面左下方到右上方的路线排列。留言增加后，路线继续延伸，后段星点更大、更亮。
- 星火谱显示留言数量和路线百分比，进度条与星点同步更新。
- 独立路线图标注“于都河”和“吴起镇”，表单及留言不会遮住路线。
- 直接打开 `index.html`，或通过 `localhost` / `127.0.0.1` 本地预览时，会显示“一键增加一束演示星火”和“减少一束演示星火”按钮：增加与撤销只作用于演示样稿，不删除手写留言；路线共10个节点，每多一条留言前进10%，达到10条后自动封顶。
- 第一次进入已有留言的星火墙时，路线与星点用约 1 秒完成一次渐亮；之后往返浏览或新增留言不会重播整段点亮。

## 五个板块

1. 首页封面：以于都河夜行、群山和路线线稿建立“走入长征”的第一意象。
2. 行军长卷：七段历史节点、连续地形背景、天气、分页配乐、四枚记忆碎片。
3. 人物专题：毛泽东作为初始主位显示在上方，其余七人位于下方循环人物长廊；点击任一人物会切换上方档案。八人使用真实、可核验的历史照片或关联现场图。
4. 星火留言墙：本机离线降级 + Node 服务端共享留言与点赞。
5. 结语：七颗星火汇聚为火炬，纪念长征胜利九十周年。

记忆碎片弹窗使用有出处的实物照片和历史照片：红军家信免贴邮票印、红军草鞋、1935年红六军团领导人合影。未找到许可明确的红军军号原物，因此使用博物馆藏同期军号实物参考，并在弹窗中明确标注，不冒充战役原件。

## 库与素材说明

- 第三方代码库：无。项目未使用 Bootstrap、Tailwind、Vue Elements、前端框架、UI 组件库、动画库或图表库。
- 后端只使用 Node.js 标准库，未使用 CMS 或后台框架。
- 场景插画和界面图标为原创内嵌 SVG。
- 人物照片、历史影像及记忆碎片均保存在项目内。来源、作者、许可和修改说明见 `docs/PHOTO_SOURCES.md`。
- 正文字体与标题字体使用 Noto Sans SC / Noto Serif SC 的本地字符子集，许可见 `docs/FONT_SOURCES.md`。
- 配乐由 Web Audio API 实时合成，没有使用外部采样、音乐库或版权音频；设计说明见 `docs/MUSIC_DESIGN.md`。

## 技术说明

- 页面使用原生 HTML、CSS 和 JavaScript。动效由 CSS 与 `requestAnimationFrame` 实现。
- 人物主档案包含一段公有领域的1930年代毛泽东无声历史影像。影像离开视口、切换人物或启用“减少动态效果”时暂停。
- 历史视频使用 `preload="none"`。封面帧和视频只在人物区进入视口时加载，记忆碎片图片按行程懒加载。
- 留言服务器使用 Node.js 标准库 `http` 模块。留言接口不可用时，页面切换到本机存储。
- 场景、图片、字体和视频均从项目目录加载，不依赖第三方资源域名。
