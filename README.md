# 长征万里，薪火千秋

一个以横向行军长卷为主线的沉浸式网页竞赛作品。用户通过拖动、滚轮、方向键或节点按钮，从瑞金于都河走到陕北吴起镇；场景、天气、分页配乐与右侧星火随行程同步变化。

## 启动

```powershell
npm start
```

打开 `http://127.0.0.1:4173`。项目只使用 Node.js 标准库，无需安装依赖。

也可以直接打开 `index.html`。此时全部前端体验可用，留言会降级保存到本机浏览器。

拖动、明暗切换与分页配乐在直接双击打开和 `npm start` 两种方式下均可用。

## 操作

- 桌面：按住长卷左右拖动，或在长卷区域使用滚轮与左右方向键。
- 手机与平板：在长卷上左右滑动。
- 所有设备：右侧或顶部的七颗星火按钮可直接跳转历史节点。
- 配乐会在首次点击、触摸、滚轮或键盘操作后自动开启；页面与七个长征章节使用不同旋律，右上角“关配乐”可随时关闭。
- 主题支持深色与浅色，偏好会保存在本机。
- 环境动效会随章节变化：湘江与赤水河包含多层水光、流动线和涟漪，夹金山叠加近远两层雪花与斜向风雪，草地带有缓慢掠过草叶的风线。
- 各章节行军剪影会以清晰但克制的速度向前行进，并配合约 0.66 秒一次的步伐起伏；抵达吴起镇时，太阳从山脊后缓慢升起并留住暖光。
- 动效粒子会按屏幕宽度自动降低密度；系统启用“减少动态效果”时，粒子与装饰性场景动画会停止。

## 五个板块

1. 首页封面：以于都河夜行、群山和路线线稿建立“走入长征”的第一意象。
2. 行军长卷：七段历史节点、连续地形背景、天气、分页配乐、四枚记忆碎片。
3. 人物专题：毛泽东作为初始主位显示在上方，其余七人位于下方循环人物长廊；点击任一人物会切换上方档案。八人使用真实、可核验的历史照片或关联现场图。
4. 星火留言墙：本机离线降级 + Node 服务端共享留言。
5. 结语：七颗星火汇聚为火炬，纪念长征胜利九十周年。

记忆碎片弹窗使用有出处的实物照片和历史照片：红军家信免贴邮票印、红军草鞋、1935年红六军团领导人合影。未找到许可明确的红军军号原物，因此使用博物馆藏同期军号实物参考，并在弹窗中明确标注，不冒充战役原件。

## 技术说明

- HTML、CSS、JavaScript 全部原生实现。
- 场景插画与界面图标为原创内嵌 SVG；记忆碎片优先使用本地保存的实物照片和历史照片。
- 人物专题使用真实照片或关联现场照片；来源、作者、许可与修改说明见 `docs/PHOTO_SOURCES.md`。
- 动画使用原生 CSS 与 `requestAnimationFrame`，未使用第三方动画库。
- 分页配乐与环境音由 Web Audio API 实时合成，未加载外部音频素材；设计说明见 `docs/MUSIC_DESIGN.md`，完整 ARR-SPEC 见 `docs/MUSIC_ARR_SPEC.yaml`。
- 未使用 Bootstrap、Tailwind、Vue Elements 或其他预设样式库。
- 留言后台使用 Node.js 标准库 `http` 模块，无第三方后台框架。
- 所有核心场景均不依赖网络下载图片或字体；留言接口不可用时自动切到本机存储。
