# 《长征万里，薪火千秋》视觉方向

## 设计判断

作品不采用“红色底 + 金色大字 + 纪念横幅”的常见模板。视觉意象来自夜间行军：炭黑是未明的路，深红是历史转折，暗金是人与人之间传递下来的微光。首屏只建立一件事——人在群山之间向前移动。

## 视觉性格

- 关键词：夜空、地形、路线、档案、克制、 monumental。
- 主记忆点：一条横向贯穿画面的行军路线，以及沿左下至右上隐线逐步延伸的星火轨。
- 构图：非对称编辑式布局，文字与场景留白交替，不使用等宽等高卡片阵列。
- 材质：细颗粒、雾、雪、江面波纹、纸纤维；不使用玻璃拟态堆叠。
- 字体：标题使用 Noto Serif SC，正文使用 Noto Sans SC。字号跨度大，正文控制在 68ch 内。
- 动效人格：Premium。主要反馈 140ms，场景切换 320ms，戏剧性点燃 680ms；默认原生 CSS 与 requestAnimationFrame。

## 色彩

| 角色 | 深色主题 | 浅色主题 | 用法 |
|---|---|---|---|
| 空间底色 | `#0D0B0A` | `#EEE4D3` | 页面与沉浸场景 |
| 历史红 | `#7D1D1D` | `#8F211E` | 节点、转折、关键操作 |
| 星火金 | `#BC8D4B` | `#805924` | 路线、星火、焦点 |
| 主文字 | `#F2EADC` | `#211814` | 标题与正文 |
| 次级文字 | `#CBBCA8` | `#55463D` | 辅助说明 |

## 版式与响应式

- 1920px：场景内容最大宽度 1680px，标题与信息形成 2:1 非对称关系。
- 1440px：保持横向节奏，首屏标题不超过视口高度的 62%。
- 720px：场景信息收为底部阅读区，星火轨移到顶部右侧。
- 375–767px：触屏左右滑动，控制按钮固定为 48px 点击区域；深度资料保持折叠。
- 桌面、平板、手机使用同一叙事顺序，不隐藏核心史料。

## 交互原则

- 设计服务于“行军”：位移必须具有方向性，氛围粒子不能抢正文。
- 进度必须可知：节点编号、年份、星火、路线进度四者同步。
- 星火用“积累”表达留言增长：首次看见星火墙时约 1 秒完成一次路线渐亮，之后只点亮新增节点。
- 所有拖拽操作均提供按钮与键盘替代。
- 配乐在用户首次点击、触摸、滚轮或键盘操作后启动；右上角一键关闭且不阻断内容。
- 画面优先，一句话解释，深度资料通过原生 `details` 展开。
