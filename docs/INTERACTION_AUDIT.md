## 修复明细

### 1. 拖拽吸附

- 原因：拖动期间为提升手感禁用了 `scroll-snap-type`，松手后浏览器没有稳定触发重新吸附。
- 修改：新增统一的最近节点判断；鼠标拖拽结束和原生 `scrollend` 都会落到完整章节，平滑滚动遵循减少动效设置。
- 复测：从第二程拖动 900px 后，最终位置回到第三程起点 `2880px`，画面不再出现两章叠加。

### 2. 离线留言状态

- 原因：网络失败只更新了单次提交状态，没有更新 `serverAvailable` 和持久说明；本机留言也没有来源标识。
- 修改：本机留言增加 `isLocal` 标记与“仅本机”标签；服务器与本机留言按时间排序；网络失败后同步切换说明；本机存储失败时保留输入并明确报错。
- 复测：离线提交后状态与说明均显示本机保存；刷新后本机留言带来源标签，说明显示本机数量。

### 3. 移动端与边界滚动

- 原因：长卷全屏覆盖并使用 `touch-action: pan-x`，纵向手势无法传递给页面；滚轮处理函数在最后一章仍调用 `preventDefault()`。
- 修改：长卷改为 `touch-action: manipulation`；触摸方向判断仅用于标记横向行军意图；滚轮在首尾边界放行页面滚动。
- 复测：393px 视口纵滑可继续浏览页面，横滑仍从第二程准确进入第三程；720px 视口在第七章继续下滚时事件不再被拦截。

### 4. 弹窗焦点闭环

- 原因：原生模态行为会阻止背景点击，但单个关闭按钮无法自动形成页面内的 Tab 循环。
- 修改：拦截弹窗内 Tab 与 Shift+Tab，在首个、末个可聚焦元素之间循环；关闭后仍将焦点返回触发按钮。
- 复测：连续 Tab / Shift+Tab 均停留在 `dialog-close` 与弹窗容器内；Escape 后焦点恢复。

### 5. 慢网提交超时

- 原因：留言 `fetch` 没有超时；服务端连接挂起时表单会一直等待。
- 修改：读取与提交统一使用 6.5 秒 `AbortController` 超时；超时按网络失败处理并保存本机。
- 复测：模拟永不返回且响应中止信号的接口，7.6 秒后按钮恢复、留言进入本机列表并显示正确说明。

### 6. 深链接规范化

- 原因：章节参数仅在实际章节大于第一程时触发 URL 同步，非法值不会回写。
- 修改：只要参数存在，就执行 1–7 夹取和 URL 回写。
- 复测：`chapter=0` 与 `chapter=abc` 均显示第一程并规范为 `chapter=1`。

## 用户反馈复测与修复

### 7. 直接打开 HTML 时全部脚本交互失效

- 现象：双击 `index.html` 打开时，只有浏览器原生滚轮滚动有效；拖动、主题和声音均无响应。
- 根因：入口脚本使用 `type="module"` 并从 `file://` 导入 `core.js`。Chrome 将该场景视为模块脚本加载失败，页面内置状态看起来正常，但没有绑定任何交互监听。
- 修复：浏览器入口改为普通 `defer` 脚本；进度换算和留言校验在浏览器入口内保留同逻辑实现。`core.js` 继续供 Node 服务端和自动测试使用。
- 回归：直接打开 `file://` 页面后，主题、声音和拖动均正常；通过 `npm start` 打开时行为一致。

### 8. 明暗状态变化但页面几乎无视觉变化

- 现象：按钮状态和 `data-theme` 已切换，但封面、长卷场景和结语仍保持固定深色，用户会认为按钮失效。
- 修复：补充完整浅色封面、浅色长卷阅读卡、浅色结语和深色半透明顶栏；主题按钮增加太阳/月亮图标切换及“转浅色/转深色”状态文字。
- 回归：切换后封面从炭黑切换为暖纸色，长卷阅读卡由深色半透明变为浅色纸面，文字和边框同步换色。

### 9. 拖动未跟手或在松手后回弹

- 现象：拖动期间 `scrollend` 会提前执行章节吸附，把指针已经拖动的位移拉回；在 Chrome 129 一类环境中，CSS 强制吸附也会与手动 `scrollLeft` 冲突。
- 修复：移除 CSS 强制滚动吸附；拖动期间暂停自动吸附；将移动与松开监听提升到窗口级，指针捕获失败时仍可拖动；超过 56px 的拖动按方向提交到相邻章节。
- 回归：拖动 120px 即从第二程进入第三程；拖动 500px 时画面实时移动，松手后准确吸附到第三程起点。

### 10. 声音状态缺少明确反馈

- 现象：内部 `aria-pressed` 和音频状态会改变，但按钮文字始终为“声音”，环境噪声又较轻微，用户难以判断开关是否生效。
- 修复：按钮文字改为“开配乐/关配乐”，提高音量，并在启用瞬间播放一次合成号角提示音。
- 回归：启用后 AudioContext 为 `running`，提示音和旋律振荡器正常启动；按钮显示“关配乐”；关闭后恢复“开配乐”并淡出。

### 11. 配乐听不到，页面之间没有音乐差异

- 现象：原实现只有低音量环境噪声和单次号角，旋律性弱；用户未手动开启时无法听到配乐。
- 修复：增加封面、七个长征章节、人物、留言墙、结语共 11 套独立旋律；首次点击、触摸、滚轮或键盘操作时自动开启配乐；右上角可随时关闭并记忆关闭状态。
- 差异化：章节之间分别使用慢速长音、低音钟声、拨弦急行、高音风雪、稀疏草地低音、铜管进行等不同速度、波形、低音与鼓点组合。
- 回归：AudioContext 状态为 `running`；乐章数据从 `ruijin` 切换至 `xiangjiang`、`jiajin`、`figures`、`spark`、`finale` 时均生成新的振荡器音符；关闭后音符调度停止。

### 12. 首页行军小队斜穿山体

- 现象：首页七个人形沿一整条斜线分布，跨过多个山峰轮廓，看起来像从山体内部穿过。
- 修复：增加一条低处前景山脊；将小队缩短并水平放置在山脊上，取消整排大角度倾斜；人物身体保持接近直立。
- 回归：桌面端与 390px 移动视口均显示为前景山脊上的横向小队，不再跨越山体，也没有页面横向溢出。
