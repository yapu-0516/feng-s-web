## 审计结论

- 页面不请求第三方域名，不依赖远程图片、字体、图表或动画库。
- 七段主视觉内嵌在 HTML 中，即使慢网也能在 HTML 到达后呈现主要叙事。
- 留言内容以 `textContent` 渲染，不使用用户输入拼接 HTML。
- 服务端限制正文大小、字段长度与连续提交频率，并串行写入消息文件。
- 当前规模为赛事单实例展示，留言保留最新 100 条、前端展示最新 33 束星火，无需引入数据库。

## 初赛提交说明

本项目未使用预设样式库或 UI 组件库；未引入第三方动画库；声音使用浏览器原生 Web Audio API 合成；后台仅使用 Node.js 标准库。可直接提交项目文件夹，并按现场环境运行 `npm start`。
