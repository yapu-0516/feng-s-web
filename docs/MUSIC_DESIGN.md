# 分页配乐设计

配乐使用 Web Audio API 即时合成，不加载外部音频文件，也不依赖第三方音乐库。浏览器限制自动播放，因此页面会在用户第一次点击、触摸、滚轮或键盘操作时启动配乐；右上角按钮显示“开配乐/关配乐”。关闭状态会保存在本机，之后不会自动开启。

音乐决策使用 `mc-workflow` 路由，并结合 `mc-arrangement-arch`、`mc-development`、`mc-melody`、`mc-harmony`、`mc-progressions`、`mc-style-cinematic`、`mc-orchestration`、`mc-sound-design`、`mc-rhythm-section`、`mc-texture-layering`、`mc-mix-intent` 与 `mc-ai-tell-audit` 完成。完整曲目规格见 [`MUSIC_ARR_SPEC.yaml`](MUSIC_ARR_SPEC.yaml)。

## 核心手法

- **星火动机**：`D4-F4-A4-G4`，八分、八分、四分、八分。它先在上行中建立方向，再由 `A-G` 回落。
- **统一与变化**：湘江做逆行与裁截，遵义只保留动机前半，赤水做快速模进，夹金山做高音宽放，草地做减缩，吴起与终章做动力再现。
- **和声铺底**：每页使用四和弦功能骨架，湘江借入 `F#dim7` 制造不稳定，避免全曲一个循环。
- **节奏与留白**：框鼓、低音与旋律分别有不同网格偏移；每 2–4 个循环出现一次刻意留白，只留下和声层。
- **音色层次**：竹笛质感承担前景旋律，低音弦乐负责背景，琵琶质感拨弦与玻璃钟琴分层进入；会师时才加入铜管。

## 技术实现

- 每个主题包含独立的速度、旋律、低音、鼓点、波形与滤波器配置。
- 音频使用 120ms 前瞻调度，避免主线程抖动造成节奏断裂。
- 场景切换会重置旋律步进，同时平滑调整环境噪声；已开始的旧音会自然衰减。
- 每个主题包含四和弦铺底、旋律、低音与鼓点层；拨弦/钟声增加二倍泛音，竹笛加入轻呼吸起振。
- 低音使用正弦基音与弱五度泛音，避免只在低频良好的监听设备上才能听见。
- 主音量经过统一增益控制，关闭时在 350ms 内淡出。
- 关闭按钮会写入 `longmarch-sound=off`，刷新后不会自动播放。

## 验收

- 11 个页面的主题均能独立切换并生成新的振荡器事件。
- 旋律、低音、拨弦存在非零抢拍/拖拍偏移。
- 湘江、草地与夹金山保留明显长留白。
- 无人声，因此演唱相关检查按纯器乐作品豁免。
- 未使用外部采样、音乐库或版权音频。
